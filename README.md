# Nepal e-GP Portal UI (Bolpatra)

Exact pixel-accurate reproduction of the **Nepal Government Public Procurement Monitoring Office (e-GP)** portal error / 404 screen.

## ✨ Features Included

1. **Government Top Strip**:
   - Official portal header identifier: `Government of Nepal Public Procurement Monitoring Office`
   - Interactive Bilingual Language Switcher (`EN` / `ने`) that seamlessly switches the entire page between English and Nepali.

2. **Official Portal Masthead**:
   - Royal blue gradient banner matching official design tokens (`linear-gradient(108deg, #2460b9, #174889, #133969)`).
   - High-definition official National Emblem of Nepal inside rounded emblem container.
   - Government, Office, and System hierarchy titles.
   - Dynamic real-time Nepal Standard Time (UTC+05:45) ticker with live clock, Bikram Sambat (BS) date, and Gregorian (AD) date.

3. **Portal Navigation Bar**:
   - Navigation links: `Home`, `Published projects`, `Help & guidance`.
   - Action buttons: Outlined `Register` button and solid `Sign in` button.

4. **Page Not Found (404) Section**:
   - Matches the exact typography and spacing of the original portal.
   - Clickable `Home` breadcrumb link.

5. **4-Column Comprehensive Footer**:
   - Brand column with Nepal emblem and mission summary.
   - `Procurement information` section.
   - `Bidder support` section with hotline, address, and training links.
   - `Important links` section.
   - Sub-footer with legal notice and Nepal timezone notice (`UTC+05:45`).

6. **Accessibility Floating Action Button**:
   - Floating widget at the bottom right with international accessibility icon.
   - Interactive accessibility panel (High Contrast, Larger Text, Monochrome, Invert Colors, Reset).

## 🚀 How to Run

You can open `index.html` directly in any web browser, or serve it using any HTTP server:

```bash
# Direct open in browser on Windows:
start index.html

# Or run with Node:
npm start
```
